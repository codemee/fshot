# macOS 虛擬螢幕分階段實作

分支：`macOS_v_screen`。

## 第一階段：既有螢幕上的作用中視窗擷取

已實作：使用者選擇既有 4K 延伸螢幕、UUID 持久化、AX 視窗身分／幾何保存、points 比例換算、ScreenCaptureKit 原生 pixels 擷取、倒數取消及錯誤還原、獨立 repeat 紀錄。

不支援：螢幕建立、控制項虛擬擷取、互動預覽。拒絕最小化／全螢幕／不可縮放視窗。

程式測試涵蓋 HiDPI 尺寸、負座標、目的螢幕配置變更、部分搬移失敗、擷取錯誤、取消與還原。原生框架方法及 UUID 橋接已確認；已使用 BetterDisplay 建立 `FShot-4K`，第一階段經使用者手動驗收通過。

驗收步驟：

1. 以 BetterDisplay 或 DeskPad 建立並啟用 3840 × 2160 延伸螢幕，授予 FShot 輔助使用及螢幕錄製權限。
2. `uv run fshot`，切換虛擬模式並選擇目的螢幕。
3. 用可調整尺寸的普通視窗按 `Ctrl+Shift+A`，確認輸出像素尺寸、原位置與大小還原。
4. 設定延遲，倒數時按 Esc；确认無新圖片且視窗還原。
5. 分別驗證 HiDPI／非 HiDPI、負座標、不同螢幕長寬比、視窗尺寸限制、目的螢幕斷線及 repeat。

## 第二階段：CLI 建立與控制項追蹤（已實作，待手動驗收）

- 使用 BetterDisplay CLI 取代直接調用未公開的 `CGVirtualDisplay`；切換模式自動選用固定名稱 `FShot-4K`，找不到時建立或重新連接，不再顯示選擇清單。
- 缺少 BetterDisplay 時詢問是否透過 Homebrew 安裝；缺少 brew 再詢問使用官方安裝程式安裝。經同意後在 Terminal 完成安裝與密碼確認，成功後自動接續建立／選用；拒絕／錯誤維持實體模式。
- 保存固定名稱與 tagID／serial／vendor／model 指紋；首次可採用同名 VirtualScreen，重試驗證身分。不重新設定其他名稱的螢幕，也不刪除舊版隨機名稱定義。退出 FShot 時保留螢幕定義與連線，使用者可在 BetterDisplay 手動斷開或移除。
- `Ctrl+Shift+W` 選取視窗標題列／外框或控制項，AX 所屬視窗與 CGWindowID 必須唯一對應；移動後重新讀取元件邊界，身分失效時中止並還原視窗。
- `Ctrl+Shift+Q` 重複同一個 native target，不再次選取其他視窗。
- 程式測試涵蓋取消、AX 所屬身分驗證、布局改變、控制項消失、repeat、CLI 逾時重試與身分變更拒絕。

手動驗收：選取非作用中視窗的標題列；選取可追蹤控制項並確認原生像素輸出；延遲時關閉／改變控制項；取消後確認視窗還原；驗證 FShot-4K 自動選取／重新連接、首次建立、安裝 BetterDisplay／Homebrew 的同意與拒絕、終端機安裝失敗／逾時重試，以及重名／身分變更拒絕設定。既有其他名稱螢幕保持不變。

## 第三階段：延遲操作預覽（已實作，待手動驗收）

- 使用 ScreenCaptureKit stream 與單張最新畫面信箱。
- 非啟用預覽保留目標鍵盤焦點；實體游標留在預覽上，Quartz event tap／CGEventPostToPSN 將映射事件提交至目標程序佇列並排除自行注入的事件；實際應用程式處理需手動驗收。
- 直接派送另需獨立的視窗內座標，目前實驗實作使用未公開的 `CGEventSetWindowLocation`／`CGEventGetWindowLocation`。開始攔截前檢查符號，派送前檢查目標身分、即時邊界及座標讀回；不支援時中止並還原，而非靜默吞掉點擊。macOS 更新後需重新驗收此相容性。
- 首張畫面就緒後才開始倒數，處理選單列與彈出視窗的擷取範圍。
- 在取消、焦點切換、目標消失、螢幕拔除與輸入錯誤後解除 event tap、釋放按鍵並還原視窗；實際游標不搬移。

僅在虛擬作用中視窗擷取、延遲大於 0 時啟用；游標需在另一個實體螢幕，啟動前放開滑鼠按鍵。指定視窗／控制項仍使用一般倒數。
最終 popup 以同程序新出現且與主視窗或目的螢幕選單列區域相交的 CGWindow 判斷，僅擷取目的螢幕內部分，無法保證所有自繪／跨螢幕選單都能納入。
程式測試覆蓋單張信箱、CV buffer 解鎖前複製、points 映射、注入事件迴圈排除、按鍵釋放、取消／焦點／輸入／串流／擷取錯誤清理及最終 popup 範圍。手動驗收需檢查輸入權限、實際預覽、拖曳與鍵盤焦點，以及結束後完整還原。
直接預覽操作另驗證：實際游標正常進出預覽、標記與視窗 annotation、預覽外不轉送、拖曳出界後放開、指定 PID 而非全域注入，以及映射游標的 HiDPI 合成。使用 Qt application／目標 NSRunningApplication 的不同參照，避免焦點恢復後退出清理中斷。
